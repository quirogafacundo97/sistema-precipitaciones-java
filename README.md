# Sistema de Precipitaciones Anuales

Proyecto realizado en Java para gestionar precipitaciones mensuales de un año.

## Funcionalidades

- Carga secuencial de precipitaciones
- Modificación de precipitaciones por mes
- Cálculo de promedio actual
- Cálculo de promedio anual
- Cálculo de desvíos respecto al promedio
- Identificación del mes más lluvioso
- Identificación del mes menos lluvioso

## Conceptos aplicados

- Programación Orientada a Objetos
- Encapsulamiento
- Arrays
- Recorridos iterativos
- Métodos de cálculo
- Validaciones básicas

## Tecnologías

- Java
- Eclipse IDE
